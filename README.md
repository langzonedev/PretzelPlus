# Pretzel Plus Website

Responsive promotional website concept for Pretzel Plus, an event-based fresh pretzel business.

## Included

- Responsive single-page layout for phone, tablet and desktop
- Mobile navigation
- Product, events, story, process, FAQ and enquiry sections
- Accessible structure, focus states and reduced-motion support
- Lightweight scroll animation and demo form feedback
- Client-supplied concept branding assets

## Local preview

Open `index.html` directly, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

Configure Pages to deploy from the `main` branch and repository root when ready.

## Before public launch

Replace placeholder photography, contact details, menu information, allergen details, social links and event claims with client-approved content. Confirm permission to publish the supplied concept branding.
