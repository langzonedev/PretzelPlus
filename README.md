# Pretzel Plus Website

Responsive promotional website concept for Pretzel Plus, a mobile, event-first pretzel business in South Australia.

## Included

- Responsive single-page layout for phone, tablet and desktop
- Mobile navigation
- Event experience, menu direction, organiser information, process, FAQ and enquiry sections
- Accessible structure, focus states and reduced-motion support
- Lightweight scroll animation and demo form feedback
- Client-supplied concept branding assets

## Local preview

Open `index.html` directly, or serve the repository locally:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## GitHub Pages

The expected public URL is:

**https://langzonedev.github.io/PretzelPlus/**

In the GitHub repository, open **Settings → Pages**, choose **Deploy from a branch**, then select the `main` branch and `/ (root)` folder. GitHub will publish the site at the URL above after the branch is deployed.

## Before public launch

Replace the labelled photography placeholders, demo contact details, menu information, allergen details and social/event links with approved content. Connect the enquiry form to the approved submission service, then confirm permission to publish the supplied concept branding.
